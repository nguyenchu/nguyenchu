Apper som skal fungere over tid

Jeg har utviklet, vedlikeholdt, publisert og støttet kundeapper for iOS og Android. Erfaringen omfatter apper brukt av titusenvis av kunder på tvers av Europa og Canada.

Jeg jobber med React Native, TypeScript og React, og har erfaring med REST, GraphQL, Firebase, Bluetooth, Wi-Fi, CI/CD og publisering i appbutikkene.

Ansvar på tvers av fag

  • Integrasjoner mot tjenester og fysiske enheter.
  • Praktisk feilsøking og oppfølging av problemer i produksjon.
  • Samarbeid med produkt, design, embedded- og backendutviklere.
  • Leveranse fra utvikling til release og videre vedlikehold.

Hvordan jeg vurderer tekniske valg

Start med kravene

React Native er en aktuell løsning når iOS og Android deler mye funksjonalitet og teamet kjenner React og TypeScript. Omfattende plattformspesifikke behov kan gjøre native eller native moduler mer aktuelt.

Vurder hele levetiden

AI kan redusere implementasjonstid. Jeg vurderer også testing på enheter, integrasjoner, vedlikehold og teamets kompetanse når jeg velger løsning.
